# report (TV5)

Báo cáo và thuyết trình.

- `report/`: bản thảo báo cáo tiếng Anh, 8 đến 12 trang.
- `report/figures/`: hình dùng trong báo cáo (lấy từ các thành viên, ghi nguồn).
- `report/slides/`: slide thuyết trình 15 phút, mỗi người một phần.

Ghép phần viết của mọi người, giữ đúng rubric của môn, kiểm tra README cuối cùng để
người ngoài chạy lại được.
